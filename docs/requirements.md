# 需求与默认值

## 产品范围

面向校园场景的轻量 Web 应用。管理员维护一份所有人共享的菜单，普通访客免登录浏览、筛选和推荐；不建立用户表、云端个人历史或跨设备个人数据同步。

## 功能

- 区域 → 店铺 → 菜品三级管理；名称、分类、备注、价格、权重和启用状态可编辑。
- 店铺分类使用 10 个固定选项：炒菜 / 家常菜、粉面 / 面食、快餐 / 盖饭、汉堡 / 炸鸡、火锅 / 麻辣烫、烧烤 / 烤肉、小吃 / 面点、轻食 / 简餐、饮品 / 甜品、其他 / 综合；新店铺默认其他 / 综合。
- 菜品分类使用 12 个固定选项：米饭 / 套餐、粉面 / 米线、炒菜 / 热菜、汉堡 / 炸鸡、披萨 / 意面、火锅 / 麻辣烫、烧烤 / 烤肉、饺馄 / 面点、小吃 / 轻食、汤粥 / 砂锅、饮品 / 甜品、其他；另有不分类（默认，存储为空字符串）。历史自定义值保留。
- 已知旧名称只用于展示和筛选匹配，不自动改写数据库：店铺「火锅 / 串串」兼容「火锅 / 麻辣烫」；旧「小吃 / 轻食」涉及拆分，不自动判定；菜品「米饭 / 盖饭」→「米饭 / 套餐」、「粉面」→「粉面 / 米线」、「主菜」→「炒菜 / 热菜」、「小吃」→「小吃 / 轻食」。
- 首页展示固定分类并标出当前区域、店铺和启用数据下的候选数量；零候选类别禁用。已映射旧名称计入对应新类别，未知历史分类只在不限类别下参与。
- 区域类型为校内食堂、校园周边、校外其他；区域支持排序。
- 支持按区域、店铺分类、店铺、菜品分类、价格上限筛选，并可排除指定店铺和菜品。店铺分类与菜品分类是相互独立的参数。
- 任一父级停用时，下级不参与公共读取和推荐。
- 管理表单把店铺和菜品的次要字段折叠，避免新录入被低频选项干扰；折叠字段在编辑时完整回填。
- 首页、历史记录和管理后台使用统一的标题区留白、字号、描述样式和标题下边距；管理工具栏与三栏卡片在窄屏下保持整齐。
- 三种推荐：
  - 随机选店：等概率选店，只展示店铺和候选菜数量；
  - 店内选菜：指定店铺内按权重选菜；
  - 两级推荐：先等概率选店，再按权重选菜。
- 店铺分类筛选只收窄店铺候选；不限类型保持 V1.0 行为。历史空分类按其他 / 综合兼容，历史自定义分类只在「不限类型」下参与，直到管理员主动归类。
- 近期去重默认关闭；开启后最近 5 次含菜品推荐涉及的菜品权重乘 0.5，店铺概率不变。
- 历史保存在当前浏览器最近 100 条，可采纳和清空；清除浏览器数据或换设备后不能恢复。
- 非空区域和店铺不允许删除，返回关联数量；数据库外键使用 `RESTRICT`，没有隐式级联删除，可停用代替。

## 首期边界

- 前端是普通 Vue 3 Web，不包含微信小程序构建；未来可复用独立推荐模块和 API，但界面适配尚未实现。
- 没有账号体系、云端个人历史、图片、地图、投稿、收藏或多角色权限。
- 演示数据是虚构的，不代表真实店铺、菜品或价格。
- 生产部署和数据库初始化属于部署者操作，不应由构建脚本自动执行。

## 管理员认证

普通用户无需登录。管理员通过应用内凭据维护共享菜单：

- Free 套餐推荐高熵访问密钥：至少 128 位、默认 256 位密码学随机密钥；服务端只保存 SHA-256 摘要并常量时间比较。
- 也可配置人工密码的 PBKDF2-HMAC-SHA256 哈希；其 CPU 开销较高，适合付费套餐且需完成云端 CPU 实测，不因超限直接降低迭代次数。
- 登录成功后由服务端下发 `HttpOnly; Secure; SameSite=Lax` 会话 Cookie；默认 12 小时绝对过期，退出立即失效。
- D1 只保存会话令牌的 SHA-256 摘要；所有管理 API 在服务端验证会话，未授权默认拒绝。
- 写请求同时校验同源 `Origin` 和 CSRF 令牌；登录失败按来源限流并返回 429。
- 生产不依赖 Cloudflare Access、`ACCESS_TEAM_DOMAIN`、`ACCESS_AUD` 或 `ADMIN_EMAILS`。

## 验收

管理创建菜单后，普通用户可以筛选并使用三种推荐；刷新或重启后菜单存在，历史使用浏览器快照。验收覆盖：

- 推荐算法、数据库约束和服务端权限；
- 类型检查、H5 与 Pages 生产构建；
- 管理登录、Cookie、CSRF、CRUD、关联删除保护、退出和未登录拒绝；
- 桌面和窄屏页面；
- 生产 D1 迁移记录、外键和完整性检查。

Free 套餐的登录 CPU 兼容性需在目标账户中按 [部署指南](deployment.md) 完成 20 次成功登录的 p95 测量；没有样本时不能宣称通过。

具体接口见 [API 契约](api.md)，模块和数据模型见 [架构说明](architecture.md)。
